COBRANET FIBER AVAILABILITY CHECKER

Deploy to Vercel:
1. Extract the ZIP file.
2. Open https://vercel.com/new and import/upload this project folder (or upload via Vercel CLI).
3. Framework preset: Other. Build command: none. Output directory: leave blank.
4. Deploy and share the generated HTTPS URL.

Data is embedded in index.html. To update coverage, regenerate the page from a revised workbook.

IMPORTANT: The source workbook says 125 streets but contains 123 numbered street records.
Street listed does not guarantee serviceability at an individual property.
